# Bot War Room V2.24 — Fixed $50 Opportunity Training

The extra post-decision sizing rules from V2.22/V2.22.1 are removed.

The Council decides whether it sees an opportunity using its existing debate/research/safety logic. Once it approves a paper opportunity:
- BUY = exactly $50
- qualified WATCH/probe = exactly $50
- winner ADD signal = exactly $50
- losing is allowed; the result is filed and learned from

The fixed-size layer does not ask whether a setup 'deserves' $12, $20 or $50.

The only unavoidable sizing constraint is actual paper-wallet cash. If less than $50 cash exists while positions are open, Executor waits for an exit rather than inventing money and corrupting wallet accounting.

A new Filing Cabinet section, **Winning with $50 Trades**, tracks trades, open positions, wins, losses, win rate, net P/L, average return and recent results.

The 100 successful fresh-coin wins requirement now counts meaningful fixed-$50 training wins, not legacy micro-trade wins.

Trades Log Buy Size uses requested BUY dollars, so new fixed entries display $50.00.
