# Bot War Room V2.25 — Early Runner Core + Entry/Exit Genome

This release returns the entire PAPER research system to the stated mission: find and study fresh coins early, learn what separates runners from dumpers, enter meaningful opportunities while they are still small, and improve exits from actual outcomes.

## Early Runner Core is now the priority lane
- $8K-$80K market cap / <=24h is treated as the early-runner research lane.
- $10K-$50K market cap receives the strongest discovery/model priority.
- Old mature-token Alpha/quorum rules do not control entries in this paper lane.
- BUY uses Runner Genome evidence as the main learned signal.
- WATCH is an active training opportunity instead of being filtered a second time by old Alpha/conviction/quorum rules.
- SKIPs continue to be followed, so missed runners remain training data.

## The mature-liquidity blockers are actually removed
The old system could still silently stop tiny runners even after the $50 sizing changes. V2.25 removes those conflicts in PAPER early-runner mode:
- the old `meme_unsafe` label no longer blocks a candidate merely because its pool is below the mature-token $20K threshold;
- the generic $15K liquidity hard floor is replaced with an early-runner absolute pool floor of $1K by default;
- actual order-size/slippage feasibility decides whether a $50+ order can realistically fill;
- the old zero starter-size from the meme classifier cannot erase an approved early-runner execution plan;
- the old $15K exit-liquidity floor no longer causes an immediate Guardian exit after entering a thin fresh pool.

Hard security failures still veto: known honeypot/unsellable behavior, top-10 >80%, bundled supply >25%, active Solana mint/freeze authorities when verified, or a pool below the absolute executable floor.

## Entry Genome background engine
Before every Council evaluation, Entry Genome compares the fresh candidate with the Filing Cabinet. It uses both live heuristics and learned nearest runner/dumper cases, emphasizing:
- market-cap zone and launch age;
- buy/sell pressure;
- 5m market-cap velocity;
- volume/MC and liquidity/MC;
- volume and transaction acceleration;
- holder / unique-buyer velocity;
- top-10 and bundled concentration.

The historical feature vector and live feature vector now use the same dimensions. The earliest observation in every case is preserved permanently so long-running cases cannot overwrite the fingerprint the model is supposed to learn from. When enough early labeled cases exist, the model trains specifically on the fresh-coin population rather than mature cases.

## $50 is the minimum — not the position size
- minimum approved PAPER entry: $50;
- learned entry sizes: $50 / $75 / $100 / $125 / $150;
- WATCH training positions can size up to $100;
- winner adds can be $50 / $75 / $100 while still respecting the per-position winner cap;
- actual paper cash remains the final accounting boundary.

No post-decision sizing rule is allowed to turn an approved opportunity into a $12 micro-buy.

## Exit Genome now learns exits too
Guardian asks Exit Genome on every fresh mark. It evaluates continuation versus distribution using live flow, acceleration, liquidity deterioration, concentration changes and the original Entry Genome thesis.

V2.25 also stores completed-trade exit quality in the Filing Cabinet:
- maximum favorable excursion;
- maximum adverse excursion;
- profit-capture percentage;
- hold time;
- final exit reason.

Once enough completed winners exist, those real exits influence trailing/hold behavior. Early-runner exit structure is runner-native rather than mature-market scalping: staged targets are +50%, +100%, +200% and +400%, with a 25% moonbag target. Entry liquidity sets the emergency liquidity floor instead of a generic $15K minimum.

## Bots are retargeted around one question
Every specialist now supports: **does this look like the beginning of a runner or the beginning of a dumper?**
- Early Runner Scout
- Narrative Ignition Scout
- Early Flow Analyst
- Runner Pattern Quant
- Fast Safety Gate
- Dumper Pattern Specialist
- Runner CIO
- deterministic Executor / Position Guardian infrastructure

Entry Genome and Exit Genome run in the background and feed learned evidence into those decisions; they do not occupy Council seats.

## Filing Cabinet = $50+ learning
`Winning with $50+ Trades` now tracks meaningful positions at or above the minimum, not just exact-$50 entries. It keeps wins, losses and missed runners. Code Deciphered's 100 fresh-coin wins must come from $50+ meaningful entries, so legacy micro wins do not graduate the system.

## PAPER research is allowed to take reps
The Early Runner Lab uses paper cash as the true exposure boundary instead of old generic mature-strategy throttles. Default research capacity is up to 20 simultaneous positions, with the old 5% paper daily-loss kill switch disabled for the early-runner lane. This is PAPER behavior only.

## Live money remains separate
No live-money graduation rule is bypassed. Code Deciphered, provider coverage, OOS accuracy, profitability requirements and the dedicated live executor remain separate gates. This update is intentionally aggressive about learning in PAPER mode, not about exposing real funds prematurely.
