# Bot War Room V2.15 — Seven-Chain Fresh Pool Scanner

## Main change
The Runner Genome now actively rotates through seven chains:

1. Solana
2. Ethereum
3. Base
4. BNB Chain
5. Monad
6. HyperEVM
7. Robinhood Chain

## Discovery upgrade
EVM chains now prioritize GeckoTerminal `new_pools` discovery before Birdeye and DEX Screener profile/boost discovery. This is intended to catch actual newly-created pools earlier.

- Solana: Birdeye new listings -> GeckoTerminal new pools -> DEX Screener -> Moralis Pump.fun fallback from the existing provider waterfall
- Ethereum: GeckoTerminal new pools -> Birdeye -> DEX Screener
- Base: GeckoTerminal new pools -> Birdeye -> DEX Screener
- BNB Chain: GeckoTerminal new pools -> Birdeye -> DEX Screener
- Monad: GeckoTerminal new pools -> Birdeye -> DEX Screener
- HyperEVM: GeckoTerminal new pools -> DEX Screener enrichment
- Robinhood Chain: Birdeye when supported -> DEX Screener fallback

GeckoTerminal calls are cached per network for 60 seconds so the public endpoint is not hammered by the 2-second Council rotation.

## Dashboard
The paper-trader panel now shows a per-chain scanner strip:
`CHAIN · scans · candidates`

This makes it obvious whether a chain is being scanned even if it has not produced the currently displayed candidate.

## Research
Every discovered candidate still flows into Runner Genome / Filing Cabinet observation and can become a runner/dumper case file even when no trade is opened.

## Safety
No new live-trading permissions are added. HyperEVM security evidence can remain incomplete if a security provider does not support the chain; paper research may continue under the existing paper-only missing-data rules, while explicit security failures remain vetoes.
