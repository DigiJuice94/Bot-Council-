- Event markers filter by selected token when viewing an individual position.
- WALLET event marker Y placement uses the nearest live portfolio-equity point.

- Event X placement is timestamp-based.
- Allocation denominator is cash + current marked open-position value.
- Cash is included as an allocation slice.
- Open positions update allocation from remaining quantity x live mark.
- Allocation card is a right-side sibling of the chart.
- Trades Log remains after the wallet-live section.
- Narrow layouts use horizontal scrolling rather than stacking the allocation below the chart.
- V2.20.2 monochrome shared chart scale remains intact.
- V2.18.2 exit hotfix, V2.17 sizing and V2.15 seven-chain scanner remain included.
