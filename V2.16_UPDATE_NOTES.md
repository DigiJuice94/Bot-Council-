# Bot War Room V2.16 — Council Group Chat

The Chat Log is redesigned as a true live group conversation.

## Chat changes
- messages render oldest at the top and newest at the bottom
- exact timestamps remain attached to every message
- the feed auto-scrolls to the newest Council message
- each bot has a stable soft color identity
- consecutive messages from the same bot are visually grouped
- current Council speaker gets a live three-dot speaking/typing indicator
- CIO messages receive a subtle final-decision emphasis
- messages are no longer truncated into table cells
- chat area scrolls independently, so a long Council debate does not make the entire page enormous

## Preserved
- original Council artwork
- V2.15 seven-chain scanner
- HyperEVM / HYPE support
- Runner Genome and Filing Cabinet
- paper wallet / multi-position execution
- provider waterfall and chain telemetry

No trading thresholds or risk rules are changed in this update.
