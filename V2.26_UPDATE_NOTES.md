# Bot War Room V2.26 — Independent Entity Council

This release changes the architecture, not just the labels.

## The Council is now eight actual entities

Seven specialist entities work privately and in parallel:

1. Early Runner Scout
2. Narrative Ignition Scout
3. Early Flow Analyst
4. Runner Pattern Quant
5. Fast Safety Gate
6. Dumper Pattern Specialist
7. Portfolio Strategist

Then the eighth entity — Runner CIO — receives their locked outputs and makes the final synthesis.

Executor is no longer a thinking Council seat. It remains deterministic infrastructure after the Council decision.

## Private phase

Each specialist receives:
- the same objective market packet;
- Runner Genome evidence;
- its own role prompt;
- only its own private memory/outcome history.

It does NOT receive any peer opinion.

All seven calls run independently. Their first opinions are locked before the meeting begins.

## Meeting phase

Only after all seven private opinions are complete:
- each entity receives its own locked opinion;
- it receives concise locked summaries from peers;
- it can keep or change its vote;
- it remains constrained to its specialty rather than merging into one generic voice.

The UI and audit log record when a vote changes.

## Runner CIO

Runner CIO is a separate eighth model call. It receives:
- the seven private reads;
- the seven meeting responses;
- objective market evidence;
- deterministic risk status.

CIO does not manufacture the specialists' opinions.

## Private memory

Each entity now has its own Redis-backed memory key. Decisions and later trade outcomes are written back to the entity that made the call.

When a position closes, each entity receives its own lesson:
- its vote/confidence;
- realized return and USD P/L;
- MFE / MAE;
- profit capture;
- whether its direction matched the eventual outcome;
- final exit reason.

This prevents one shared memory blob from becoming a single disguised brain.

## True AI mode requires an API key

Set `OPENAI_API_KEY` in Railway Variables.

Defaults:
- seven specialists: `gpt-5.6-luna`
- Runner CIO: `gpt-5.6-terra`

By default, if the key is missing, the system errors rather than silently pretending the old single-engine role simulation is a true independent AI Council.

`COUNCIL_ALLOW_DEGRADED_FALLBACK=false` is the default.

An explicit isolated local fallback mode exists for outages, but the dashboard labels it clearly and does not call it independent AI.

## Early Runner Core remains intact

V2.25 Runner Genome, Exit Genome, $10K-$50K priority, $50 minimum adaptive sizing, $50+ Filing Cabinet, seven-chain discovery, token images, CA copy, USD P/L and Guardian logic remain in place.

The common deterministic analytics engine still calculates objective metrics such as risk, Alpha, regimes, Runner Genome and exit data. Its old synthetic role opinions are discarded and do not decide the V2.26 Council.
