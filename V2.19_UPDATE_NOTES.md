# Bot War Room V2.19 — Live Wallet + Position Charts

A new **Live Wallet & Positions** section now sits directly above the Trades Log.

## Live portfolio chart
- updates from the same `/api/autopilot` payload used by the wallet and Guardian
- stores up to 240 recent equity marks in the browser
- plots current wallet equity against the starting-wallet reference line
- updates automatically as open positions move

## Live position charts
Every open position can show:
- live marked price path
- entry line
- stop-loss line
- first take-profit line
- entry, current price, high-water mark and stop
- current P/L and Guardian winner state

Up to eight open positions are shown, matching the current normal position cap.

## Wallet audit
The same section now separates:
- cash
- open-position cost
- current open-position value
- unrealized P/L
- realized P/L
- equity

It also performs a client-side reconciliation check: `cash + marked open positions = displayed equity` within a 10-cent tolerance. A mismatch is surfaced as **RECONCILIATION ERROR** instead of being hidden.

## Placement
This section is directly **above Trades Log**, as requested.

V2.18.2 Guardian exit-liquidity fixes, V2.18 paced chat, V2.17 sizing, and V2.15 seven-chain scanning are preserved.
