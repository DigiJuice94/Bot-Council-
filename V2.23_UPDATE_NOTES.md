# Bot War Room V2.23 — Token Images + Rich Trade Tracking

## Coin images
The live decision card now uses the real token image whenever the provider supplies one.

The system attempts images from:
- DEX Screener pair `info.imageUrl`
- image/logo fields present in discovery records
- GeckoTerminal image field when available

If no image is available, or a remote image fails to load, the clean letter-avatar fallback remains.

Images are persisted into managed positions so the Trades Log and holdings allocation can keep showing them during the trade.

## Trades Log
The Trades Log now shows:
- token image
- ticker
- shortened contract address
- COPY button for the full CA
- chain
- total position buy size in USD
- entry
- current mark / exit
- status
- P/L percentage
- P/L in USD
- trade age

For open trades, USD P/L uses current marked remaining value + realized proceeds - total position cost.
For closed trades, USD P/L uses realized P/L.

No trading, wallet accounting, exit, scanner, research, sizing or live-gate rules changed.
