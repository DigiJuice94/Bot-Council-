The Railway failure `npm error Missing script: "build"` was caused by the repository's
root `package.json` being a different Express/DTL project package and containing only a
`start` script.

This rescue package restores the Bot War Room Next.js package manifest with:

- `npm run build` -> `node prepare-structure.mjs && next build`
- Next.js 16.3.3
- React / React DOM 19.3.0
- Redis dependency
- TypeScript + React/Node type packages

Upload/replace `package.json` at the repository root along with the rest of V2.18.1.
Railway's existing Dockerfile can then run `npm run build`.
