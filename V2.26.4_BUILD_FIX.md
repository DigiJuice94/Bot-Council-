# Bot War Room V2.26.4 — Railway Typecheck Scope Fix

Railway reached Next.js type checking and failed on root-level files:

- `agent-entity-runtime.ts`
- `agent-entity-store.ts`
- `runner-research.ts`

Those root files are flat source templates used by `prepare-structure.mjs`. They are copied into `lib/` and then patched there before Next builds.

The old `tsconfig.json` used `**/*.ts`, so TypeScript was compiling BOTH:

1. the unpatched root template files; and
2. the final patched files under `lib/`.

That is why TypeScript claimed the independent-Council types and `runnerGenome` fields did not exist even though the build patches had successfully added them to generated `lib/types.ts`.

V2.26.4 scopes TypeScript to the actual Next.js runtime tree only:

- `app/**`
- `components/**`
- `lib/**`
- Next generated types

The root flat templates remain available for `prepare-structure.mjs`, but they are no longer incorrectly compiled as runtime source.

No strategy behavior changed.

Preserved:
- 8 independent Council entities
- Early Runner Core
- Entry Genome / Exit Genome
- $50 minimum adaptive sizing
- PAPER portfolio kill switches OFF
