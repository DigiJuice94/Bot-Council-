# V2.26.1 Railway Build Fix

Railway stopped inside `early-runner-core-patch.mjs` with:

`Could not find patch anchor: dynamic $50+ Runner Genome sizing`

The feature logic itself was not the failure. The V2.25 patch was matching the exact text emitted by the older V2.24 sizing patch. That is too fragile when the repository contains a slightly different prior source revision.

V2.26.1 replaces those fragile full-block matches with structural boundaries:

- `executeRequest()` sizing section is located by the function header and `entryContext` boundary.
- WATCH/probe logic is located by `explorationRequest()` and its `return` boundary.
- winner-add sizing is located by the scale-in calculation and `executePaper()` boundary.

This preserves the V2.25 Early Runner Core and V2.26 Independent Entity Council while making the cumulative Railway build tolerant of the exact prior patch text.

No trading behavior was intentionally made more cautious or otherwise changed in this build fix.
