# Bot War Room V2.14.1 — Decision Card Layout Polish

This cumulative update keeps all V2.13/V2.14 Runner Genome + Filing Cabinet behavior and applies the requested Council-stage layout cleanup.

## UI changes

- Council stage is now pure white; the gray/radial background band is removed.
- Current Decision card no longer uses an outer border; the card is separated from the page with soft shadow only.
- Card is moved upward.
- Card is wider and shorter so it reads as a cleaner rectangle and uses less vertical space.
- Internal spacing, stat height and BUY/WATCH/SKIP button height are tightened.
- The extra vertical clearance reduces collisions with the CIO / Council chat bubble.
- Mobile spacing is tightened separately so the card remains readable without taking over the bot scene.

## Multiple concurrent buys

The Council already supports multiple open positions on different tokens. The paper portfolio default is `PAPER_MAX_OPEN_POSITIONS=8`, so up to eight different positions can be open at the same time, subject to portfolio exposure, per-chain exposure, available cash, hard risk gates and Council approval.

The same token is not opened as a duplicate position. Position Guardian owns that token and can scale the existing position instead. The autonomous scan loop evaluates candidates sequentially, but approved positions remain open concurrently.
