# Bot War Room V2.29 — Trajectory Observer

V2.29 adds a **background-only Trajectory Observer**. It is not a ninth Council vote and it cannot buy, sell, veto, or size a trade by itself.

## What it watches

Every fresh case keeps being followed after BUY, WATCH, or SKIP. The Observer studies the sequence instead of only the current snapshot:

- market-cap growth per minute
- market-cap acceleration
- buy/sell pressure changes
- volume-acceleration changes
- holder-velocity changes
- unique-buyer-velocity changes
- liquidity/market-cap trend
- pullback depth
- recovery strength
- distribution/fade patterns

The default fresh-case review cadence is ~30 seconds (`TRAJECTORY_OBSERVER_REVIEW_MS=30000`).

## How it learns

The Observer compares the current multi-snapshot path with previously labeled runner and dumper paths. It prefers a chain-specific model once enough labeled sequences exist on that chain; otherwise it uses the broader labeled population without pretending the chain model is mature.

It classifies development phases such as:

- IGNITION
- ACCELERATION
- PULLBACK
- RECOVERY
- DISTRIBUTION
- STALLED

## How the trading bots receive the feedback

When a case becomes a runner or dumper, the Observer writes a different private lesson to each Council entity:

- Early Runner Scout: launch-development/acceleration lesson
- Early Flow Analyst: buy/sell, holder and unique-buyer velocity lesson
- Runner Pattern Quant: numeric sequence signature
- Dumper Pattern Specialist: failed/recovery trajectory lesson
- Portfolio Strategist: sizing context for similar future paths
- Narrative Ignition Scout: verified social-velocity trajectory context
- Fast Safety Gate: liquidity-behavior context without weakening hard safety
- Runner CIO: overall sequence lesson

Those lessons remain inside each entity's existing private Redis memory. The Observer itself is not added to the Council roster.

## How it changes future trades

Trajectory guidance is now part of Runner Genome guidance. Once a token has enough time-separated observations, the sequence score can influence:

- Early Runner Scout
- Early Flow Analyst
- Runner Pattern Quant
- Dumper Pattern Specialist
- Portfolio Strategist
- Runner CIO synthesis

The weighting is intentionally bounded. A new coin with only one observation gets **INSUFFICIENT** trajectory confidence, so the Observer cannot invent a pattern from a single snapshot.

Past trajectory lessons also calibrate a specialist when a future coin enters a similar trajectory phase, with same-chain lessons weighted more strongly.

## Filing Cabinet UI

The Runner Genome section now includes a **TRAJECTORY OBSERVER · BACKGROUND ONLY · NO VOTE** panel showing:

- sequences tracked
- labeled sequences
- runner paths
- dumper paths
- mature chain-specific models
- review cadence
- latest trajectory lessons
