# Bot War Room V2.21 — Portfolio Trade Events + Live Allocation

## Portfolio graph
The existing black-and-white FOMO-style graph now displays actual paper-wallet fill events from `recentFills`.

Markers include:
- BUY
- ADD1 / ADD2 / ADD3 when encoded in the decision ID
- TP1 / TP2 / TP3
- SELL
- EXIT

On the WALLET view the event is pinned to the closest portfolio-equity point at its timestamp.
On an individual token view it is pinned to that fill's execution price.

Hovering a marker shows token, event type, time, fill price and filled dollar value.

## Current holdings allocation
A monochrome holdings donut now sits permanently to the RIGHT of the main graph.

The donut includes:
- cash
- every currently open position
- current dollar value
- percentage of total current portfolio value

The legend updates automatically as Guardian marks positions, adds, trims or closes them.

The holdings panel does not move underneath the chart. On narrow screens the combined graph + holdings area becomes horizontally scrollable instead.

## Layout
Trades Log remains directly BELOW the entire graph/allocation row exactly as requested.

No trading, Guardian, wallet accounting, scanner, research or live-gate rules were changed.
